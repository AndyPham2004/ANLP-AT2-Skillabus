# 2 Related work

**Skill extraction.** ESCO (European Commission, 2017) gives a shared, multilingual skill inventory that most research systems map to. SkillSpan (Zhang, Jensen, Sonniks & Plank, 2022) annotated skill spans in English job ads, and a weak-supervision follow-up linked spans to ESCO by embedding similarity (Zhang, Jensen, van der Goot & Plank, 2022). Both note that a fixed inventory misses new skills. Large language models now extract skills from ads, resumes and course descriptions with few examples (Frej et al., 2024); an LLM can, however, return skills that are not in the text. This motivates our design: a vocabulary lookup as the precise backbone, spaCy and GPT-4o-mini for what it misses (with every skill checked against the text), and an explicit class for skills ESCO lacks.

**Job–resume matching.** LinkedIn’s Skills Match and resume checkers such as Jobscan compare a profile or resume with a job. They stop at “add this keyword” or point to their own short courses, never to a university subject, and they show no evidence for a match.

**Course recommendation.** Karakolis et al. (2022) recommend university courses from a learner’s CV using ESCO, but read course descriptions only and show relevance scores instead of evidence. Skill Scanner (Schlippe & Bothmer, 2023) embeds ads, CVs and one master’s curriculum and reports which market skill clusters a document covers, without recommending subjects. JCRec (Frej et al., 2024) uses reinforcement learning to choose course sequences that maximise the jobs a learner qualifies for, evaluated on simulated users. UniSkill (Musazade, Mezei & Zhang, 2026) shows that sentence-level course–skill matching works with fine-tuned encoders, which supports sentence embeddings over keywords for subject evidence. None of these evaluates recommendations against labelled ground truth.

**Closest system.** Lightcast Skillabi (Lightcast, 2025) maps curriculum text to the Lightcast taxonomy and scores how well a program aligns with occupations: it compares “taught” with “sought” skills, as we do. It works at program level for program leaders, is proprietary, and shows no evidence sentences. The similar names are a coincidence.

**The gap Skillabus fills.** No system we found does all of the following for one student and one target ad or role: finds the gaps in their resume, links each gap to a specific UTS subject with the Handbook sentence that justifies it (from learning objectives, assessments and weekly topics, not only the description), ranks gaps by Australian ad demand, chooses the two or three subjects the student can actually enrol in, and keeps skills that ESCO lacks. Each stage is measured against a baseline on hand-labelled data (section 6).
